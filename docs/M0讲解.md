# M0 讲解：骨架是怎么搭起来的

## 1. 这次做了什么

让一只"占位小团子"出现在桌面右下角：透明背景、没有标题栏、永远置顶、不占任务栏；
右下角系统托盘里多了一个小图标，右键可以"显示/隐藏"或"退出"。

它现在还不会动、不能点——那是 M1 的内容。

## 2. 文件都是干什么的（用"餐厅"打比方）

| 文件/文件夹 | 作用 | 比方 |
|---|---|---|
| `.venv\` | Python 虚拟环境，本项目专用的"工具箱"，所有第三方包装在这里 | 独立工具箱，不跟别家项目混用 |
| `app\main.py` | 程序入口，负责组装并启动 | 餐厅大门和总闸 |
| `app\pet_window.py` | 桌宠窗口：长什么样、放在哪 | 舞台 |
| `app\tray.py` | 系统托盘图标和菜单 | 后台遥控器 |
| `启动宠物.bat` | 双击启动，不用敲命令 | 一键开机按钮 |
| `requirements.txt` | 记录依赖了哪些第三方包 | 工具箱采购清单 |
| `tools\` | 开发期用的侦察/探针脚本 | 施工仪器 |

## 3. 几个你以后会反复听到的概念

- **虚拟环境（venv）**：每个 Python 项目自带一份独立的包，互不干扰。我们所有命令都用
  `.venv\Scripts\python.exe`，而不是系统里随便一个 python。
- **窗口标志（Window Flags）**：`pet_window.py` 里那几行 `Qt.xxxHint` 决定窗口性格——
  无边框、置顶、不进任务栏。
- **事件驱动**：程序不是"从上到下跑完就结束"，而是启动后等着——你点鼠标、它该重画了，
  就触发对应的函数（比如 `paintEvent` 负责每次画面重绘）。

## 4. 怎么启动和退出

1. 双击 `启动宠物.bat`。
2. 退出：托盘里找到小图标 → 右键 → **退出**。
   （直接关 bat 黑窗口也能退出，但不推荐。）
